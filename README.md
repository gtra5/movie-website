# Movie Website

This is a modern web application for browsing, searching, and discovering movies. Built with React and Vite, the project features a clean user interface, movie filtering, detailed movie pages, and responsive design.

## Features

- Browse a curated list of movies
- Search for movies by title or keyword
- Filter movies by genre or other criteria
- View detailed information for each movie
- Responsive layout for desktop and mobile
- Modular React components for easy maintenance

## Project Structure

```
my-movies/
  public/           # Static assets
  src/
	 assets/         # Images and icons
	 components/     # Reusable UI components
	 pages/          # Main pages (Home, Movie Details, Search)
	 App.jsx         # Main app component
	 main.jsx        # Entry point
	 ...
  package.json      # Project dependencies and scripts
  vite.config.js    # Vite configuration
```

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Open your browser:**
   Visit [http://localhost:5173](movie-website-self.vercel.app) to view the app.

## Scripts

- `npm run dev` – Start the development server
- `npm run build` – Build the app for production
- `npm run preview` – Preview the production build
